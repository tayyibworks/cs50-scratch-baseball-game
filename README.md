# Baseball Game — CS50 Scratch Project

## About
A simple baseball game created using Scratch as my Harvard CS50 Week 0 project.

The objective is to hit the baseball, score points and avoid getting three strikes.

## Features
- Start screen and game-over screen
- Player movement
- Scoring system
- Three-strike system
- Increasing game difficulty
- Background music
- Restart functionality

## Controls
- **Left Arrow:** Move left
- **Right Arrow:** Move right
- **Space:** Start the game and hit the ball
- **R:** Restart the game

## Technologies Used
- Scratch 3.0

## Project File
The `.sb3` file is included in this repository.

## What I Learned
- Scratch programming
- Variables and conditionals
- Loops and broadcasts
- Custom blocks
- Game logic and debugging
